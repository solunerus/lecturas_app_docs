# Capturar lecturas

Para capturar lecturas es necesario iniciar sesión como
[empleado](/docs/iniciar-sesion/empleado). Al elegir esta opción se abrirá una
pantalla donde deberás seleccionar **una ruta**, previamente descargada desde
[Bajar rutas](/docs/lecturas/bajar-rutas).

Al seleccionar la ruta a capturar verás la lista de todos
los medidores que pertenecen a esa ruta. Para agilizar la búsqueda del medidor que necesitas,
cuentas con las siguientes herramientas:

1.  **Búsqueda rápida**: escribe cualquiera de los datos visibles, como dirección, número de
    cuenta o número de medidor.

2.  **Búsqueda específica por número de localización**: escribe el número de 16 dígitos que se
    encuentra en la parte inferior del medidor para localizar exactamente el que necesitas
    consultar.

3.  **Localización de medidor y toma de agua**: en la parte inferior de cada fila encontrarás un
    ícono de mapa que muestra la ubicación exacta del medidor, así como la de su toma de agua.

4.  **Consultar búsqueda anterior**: este botón, ubicado en la parte inferior derecha de la
    pantalla, te muestra el último medidor que consultaste antes de salir de esta ventana.

    src="/img/arquos_opr/usuarios/lecturas-usuarios/usuarios-lecturas-5.jpg"

Una vez que localices y selecciones el medidor a capturar, se abrirá una nueva ventana con los
datos del medidor, donde podrás registrar lo siguiente:

1. Dentro del **menú de captura** encontrarás:
   - La lectura actual.
   - El campo para escribir la lectura del medidor.
   - Un espacio para anotar alguna observación.
   - La opción de seleccionar una **anomalía**, en caso de haberse presentado.
   - La opción de **añadir una fotografía** de la condición actual del medidor.
   - El botón para **guardar cambios**.
2. Al seleccionar **anomalía** encontrarás:
   - Un listado de anomalías predefinidas, del cual podrás elegir la que corresponda.
   - Un buscador rápido para localizar una anomalía específica.
3. Al seleccionar **añadir fotografía** encontrarás dos opciones:
   - Tomar una fotografía en el momento.
   - Elegir una fotografía existente desde la galería del dispositivo.
4. Al presionar **guardar cambios** se te pedirá verificar la información; si todo está correcto, selecciona **guardar** para confirmar la captura del medidor.

Si al momento de tomar una foto o adjuntar alguna de tu galería deseas eliminarla, puedes hacerlo:
mantén pulsada la imagen un momento y arrástrala a la parte inferior de la pantalla, justo sobre
el ícono de papelera que aparecerá en lugar del ícono de agregar imagen.

<div className="doc-img-single">

Una vez capturados los datos del medidor y agregada una fotografía o anomalía si esta era necesaria, presiona
el botón de guardar cambios para confirmar la captura. El medidor quedará
guardado y listo para enviarse: en el listado se mostrará en color **amarillo** mientras esté
pendiente de envío, y en color **naranja** una vez que ya haya sido enviado.
