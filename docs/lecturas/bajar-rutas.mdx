# Bajar rutas

Puedes descargar las rutas registradas en el sistema; estas están organizadas de forma que sea
fácil localizar una ruta específica. La aplicación te pedirá elegir **un subsistema**, después
un **sector** dentro de ese subsistema y, por último, la **ruta** que deseas descargar.
