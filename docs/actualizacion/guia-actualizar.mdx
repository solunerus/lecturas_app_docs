# Guia de actulización

Aqui se resolveran las dudas mas frecuentes sobre las actualizaciones de Arquos OPR
y como tener la versiona mas reciente en todo momento ademas de saber como
verificarlo por uno mismo.

## Verifica la Play Store

Utiliza la busqueda de aplicaciones de la Play Store para encontrar a `Arquos OPR`,
una vez ubicado verifica si este cuenta con un boton que diga **actualizar (1)** si es
asi presiona la opcion de actualizar, en caso contrario de no tener la opcion de
actualizar significa que tienes las version mas reciente por lo que no sera
necesario actualizar, ademas este boton dira **abrir (2)**.

## Verifica desde la aplicacion de Arquos OPR

Para verificar la versión que se esta usando desde la aplicación de `Arquos OPR` dirígete
al menu desplegable izquierdo en la opcion de `Configuración`, dentro te dirigiras a la
parte superior derecha en el icono que tiene el **signo** de `?`, una vez dentro se te
mostraran las especificaciones tanto del dispositivo que estas usando como informacion
general de la aplicación, ahi podras verificar la version que estas usando.
