# Empleado

Para iniciar sesión como empleado, es necesario estar previamente registrado y dado de alta en
el sistema. Una vez cumplido este requisito, selecciona la opción **Iniciar sesión - Empleado**
en el menú lateral izquierdo.

<div className="doc-img-single">
  <img
    src="/img/arquos_opr/introduccion/iniciar_sesion/iniciar_sesion_1.png"
    alt="Menú lateral con la opción Iniciar sesión - Empleado señalada"
  />
</div>

A continuación, busca tu usuario dentro del listado; al encontrarlo, selecciónalo e ingresa tu
contraseña para completar el inicio de sesión.
