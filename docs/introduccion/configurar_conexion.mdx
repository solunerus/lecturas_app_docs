# Configurar conexión

Antes de poder utilizar **Arquos OPR**, la aplicación necesita conectarse al servidor del
organismo operador de agua correspondiente a tu región. Esta conexión se establece mediante una
**URL API**, que es la dirección que le indica a la aplicación con qué servidor debe
comunicarse para consultar y sincronizar la información de rutas, medidores y órdenes de
trabajo.

Si aún no cuentas con esta URL, solicítala al administrador del sistema en tu organismo antes de
continuar.

### Pasos para configurar la conexión

1. Escribe la **URL API** en el campo correspondiente, dentro de la ventana **Configurar
   conexión**.
2. Presiona el ícono azul ubicado a la derecha del campo **URL API** para validar los datos
   ingresados.

<div className="doc-img-single">
  <img
    src="/img/arquos_opr/introduccion/configurar_conexion/conf_conexion_1.png"
    alt="Validar la URL API ingresada"
  />
</div>

3. Una vez validada la **URL API**, se mostrará la información del organismo asociado a esa
   dirección: **Organismo, RFC, Dirección y Fecha**. Verifica que estos datos correspondan a tu
   organismo antes de continuar.
4. Presiona el botón ubicado en la parte superior derecha para **guardar** la configuración.

<div className="doc-img-single">
  <img
    src="/img/arquos_opr/introduccion/configurar_conexion/conf_conexion_2.png"
    alt="Guardar la configuración de conexión"
  />
</div>

Una vez guardada la conexión, tendrás acceso a la interfaz principal de **Arquos OPR**, desde
donde podrás llegar al [menú de usuarios](/docs/category/usuarios), así como al
menú plegable lateral.
