# Configurar conexión

En este sistema es necesario contar con una URL API para hacer uso y poder
Conectarse directamente con la empresa de la región.

**1**) En caso de que ya cuentes con esta tendras que escribirla en el apartado
de **URL API** el cual aparece en la ventana de **Configurar Conexión**, no es
necesario escribir algo en el apartado de dispositivo.

**2**) Cuando lo hayas completado el formulario, tendras que presionar el icono de
color azul que esta en la parte derecha del apartado **URL API**, donde se
validaran los datos.
