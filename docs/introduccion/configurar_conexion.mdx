# Configurar conexión

En este sistema es necesario contar con una URL API para hacer uso y poder
Conectarse directamente con la empresa de la región.

En caso de que ya cuentes con esta tendras que escribirla en el apartado
de **URL API** el cual aparece en la ventana de **Configurar Conexión**,
Cuando lo hayas completado el formulario, tendras que presionar el icono de
color azul que esta en la parte derecha del apartado **URL API**, este se
encargara de validaran los datos.

<center>
  <img
    src="/img/arquos_opr/introduccion/configurar_conexion/conf_conexion_flecha.png"
    alt="Imagen conexion validada"
    width="300"
  />
</center>

Cuando la **URL API** haya sido validada correctamente, se mostrarán los datos
de la empresa (Organismo, RFC, Dirección y Fecha) corrobore que los datos sean correctors.
Por último, guarda la información; con el botón se encuentra ubicado en la parte superior
derecha.

<center>
  <img
    src="/img/arquos_opr/introduccion/configurar_conexion/conf_conexion_guardar.jpg"
    alt="Configurar conexion menu principal"
    width="280"
  />
</center>

Una vez realizado lo anterior, tendremos acceso al interfaz principal de Arquos
OPR, donde se logran ver las ventanas de [lecturas](/docs/usuarios/inicio-usuarios#1---lecturas),
[validación](/docs/usuarios/inicio-usuarios#2---validación) y [ordenes](/docs/usuarios/inicio-usuarios#3---órdenes),
ademas del menu plegable.
