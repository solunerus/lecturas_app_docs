# Iniciar sesión

Iniciar sesión habilita las funciones principales de **Arquos OPR**, como la captura y el envío
de lecturas, validaciones y órdenes de trabajo. La aplicación cuenta con dos tipos de acceso,
según el rol del usuario: `Empleado` y `Administrador`.

## Empleado

Para iniciar sesión como empleado, es necesario estar previamente registrado y dado de alta en
el sistema. Una vez cumplido este requisito, selecciona la opción **Iniciar sesión - Empleado**
en el menú lateral izquierdo.

## Administrador

Para iniciar sesión como administrador, selecciona la opción **Iniciar sesión - ARQUOS** en el
menú lateral izquierdo. A diferencia del inicio de sesión como empleado, aquí **no es necesario
buscar ningún usuario en un listado**: el acceso de administrador se hace directamente con tus
credenciales.

Al seleccionar esta opción, se mostrará una ventana solicitando dos datos:

1. **Usuario ARQUOS**: tu nombre de usuario de administrador.
2. **Contraseña**: tu contraseña de acceso.

Una vez capturados ambos campos, presiona **Iniciar** para acceder a la aplicación con permisos
de administrador. Si deseas cancelar el proceso, presiona **Cancelar**.

:::note[IMPORTANTE]

Algunas funciones de la aplicación, como [enviar la ruta de validación](/docs/usuarios/inicio-usuarios#23---enviar-ruta-de-validación),
requieren haber iniciado sesión como administrador.

:::
