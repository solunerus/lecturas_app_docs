# Validación

Desde este apartado podrás [bajar](/docs/validacion/bajar-rutas),
[capturar](/docs/validacion/capturar-validacion) y
[enviar](/docs/validacion/enviar-ruta) las rutas de validación de los medidores. La información
se organiza por rutas, lo que te permite descargar únicamente las que necesitas, registrar los
datos de cada medidor en campo y enviarlos al servidor una vez concluido el trabajo.
