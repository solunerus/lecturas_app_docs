# Enviar ruta de validación

Para enviar una ruta de validación es necesario iniciar sesión como
[Usuario Arquos](/docs/iniciar-sesion/usuario-arquos). Cuando tengas guardado al
menos un medidor de alguna ruta de validación, podrás enviarlo al servidor. Al igual que en la
captura, verás el listado de rutas y podrás elegir enviarlas todas de una vez o seleccionarlas
una por una. En ambos casos aparecerá un mensaje de confirmación preguntando si deseas
continuar; si las capturas son correctas, presiona **continuar** para enviar los datos.
