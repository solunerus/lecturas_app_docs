# Enviar ruta de validación

Para enviar rutas de validación es necesario iniciar sesión como
[Usuario Arquos](/docs/iniciar-sesion/usuario-arquos). Cuando tengas guardado al menos un
medidor de alguna ruta, podrás enviarlo al servidor. Verás el listado de rutas capturadas y
podrás elegir enviarlas todas de una vez o seleccionarlas una por una. En ambos casos aparecerá
un mensaje de confirmación preguntando si deseas continuar; si las capturas son correctas,
presiona **continuar** para enviar los datos.

:::note[IMPORTANTE]

El envío de datos al servidor puede tardar algunos minutos, dependiendo de la velocidad de tu
conexión a internet.

:::

En caso de querer **eliminar** las rutas capturadas, puedes hacerlo mediante el ícono rojo en forma
de papelera que aparece al lado de cada ruta, ya sea para eliminar todas o solo una en
específico. Antes de eliminar se te pedirá confirmar la acción.
