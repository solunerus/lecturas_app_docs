# Más configuraciones

Para ajustar a tus preferencias la configuración con la que tomas y guardas las capturas,
puedes entrar al menú de **Más configuraciones**. Para encontrar esta opción habilitada debes
iniciar sesión como [Usuario Arquos](/docs/iniciar-sesion/usuario-arquos) y después
puedes seguir esta ruta:

1. Despliega el menú del lado izquierdo y selecciona la opción de **Configuración**.
2. Una vez dentro, dirígete a la parte superior derecha y selecciona la opción de **Más configuraciones**.

Dentro de esta opción encontrarás un menú de configuraciones que puedes modificar a tu
preferencia; estas son las siguientes:

1. **Email**: cambia el correo del usuario y, si lo deseas, activa el interruptor **NO ENVIAR**
   para desactivar el envío de notificaciones por correo al subir información al servidor.
2. **PERMISO DE LOCALIZACIÓN**: al activarlo, permites a la aplicación el uso de tu ubicación.
3. **PERMISO DE CÁMARA**: al activarlo, permites que la aplicación use la cámara del dispositivo.
4. **PERMISO DE FOTOS**: al activarlo, le niegas a la aplicación el acceso a las fotos de la
   galería de tu dispositivo.

También existen algunas opciones avanzadas para tener un mayor control sobre las imágenes
capturadas desde la aplicación. Estas opciones son las siguientes:

5. **SELECCIONAR LA CALIDAD DE IMAGEN**: puedes elegir el tamaño o la calidad mínima de la imagen que se
   adjunta al subir información al servidor, tanto si la imagen se tomó desde la aplicación como si se
   seleccionó de la galería del equipo.
6. **SOLICITAR GPS**: mantenerla activa hace que la aplicación haga uso del GPS.
7. **GUARDAR EN GALERÍA**: mantenerla activa hace que se guarde una copia de las imágenes tomadas
   desde la aplicación en tu galería.
8. **AGREGAR MARCA DE AGUA**: tenerla activada añade una marca de agua a las imágenes, tanto a las
   tomadas desde la aplicación como a las seleccionadas desde la galería de tu equipo.

A continuación se añade una imagen de cómo sería la configuración recomendable para la aplicación.
Recuerda que es solo una recomendación: si deseas desactivar alguna opción, puedes hacerlo.
