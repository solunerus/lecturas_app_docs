# Más Configuraciones

Para ajustar a tus preferencias la configuración con la que tomas y guardas las capturas,
puedes entrar al menú de **Más configuraciones**. Para encontrar esta opción habilitada debes
iniciar sesión como [Usuario Arquos](/docs/iniciar-sesion/usuario-arquos) y después
puedes seguir esta ruta:

1. Despliega el menú del lado izquierdo y selecciona la opción de **Configuración**.
2. Una vez dentro, dirígete a la parte superior derecha y selecciona la opción de **Más configuraciones**.

Dentro de esta opción encontrarás un menú de configuraciones que puedes modificar a tu
preferencia; estas son las siguientes:

1. **Email**: dentro de las opciones de email, podremos cambiar el correo del usuario y al activar el
   interruptor **NO ENVIAR** para desactivar el envío de notificaciones por correo al subir información al servidor.
2. **PERMISO CONCEDIDO DE LOCALIZACIÓN**: al activarla permites a la aplicación el uso de tu ubicación.
3. **PERMISO CONCEDIDO DE CÁMARA**: al activarla permites que la aplicación use la cámara del dispositivo.
4. **PERMISO DENEGADO DE FOTOS**: negarle a la aplicación el acceso a las fotos de la galería de
   tu dispositivo.

También existen algunas opciones avanzadas para tener un mayor control sobre las imágenes
capturadas desde la aplicación. Estas opciones son las siguientes:

5. **SELECCIONAR LA CALIDAD DE IMAGEN**: puedes elegir el tamaño o la calidad mínima de la imagen que se
   adjunta al subir información al servidor, tanto imagen tomada desde la aplicacion como tomada de la
   galeria del equipo.
6. **NO SOLICITAR GPS**: mantenerla activa hace que la aplicación haga uso del GPS.
7. **NO GUARDAR EN GALERÍA**: mantenerla desactivada hace que se guarde una copia de las imágenes tomadas
   desde la aplicación en tu galería.
8. **SI AGREGAR MARCA DE AGUA**: tenerla activada añade una marca de agua a las imágenes tomadas desde la aplicacion como
   seleccionadas desde la galeria de tu equipo.

A continuacion se añade una imagen de como seria la configuración recomendable para la aplicación, recuerda que es una
recomendación si deseas desactivar alguna opcion puedes hacerlo.
