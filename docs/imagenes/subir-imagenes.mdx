# Subir y eliminar imágenes

Otra de las opciones utiles que se encuentra al alcance izquierda se encuentra la opcion de **subir imagenes** que han sido adjuntadas al
momento de capturar los datos, una vez dentro ademas de ver las imagenes adjuntas, podremos ver algunos de los datos
generales de cada captura realizada y con ayuda de lo botones **Enviar imágenes** y **Eliminar imágenes**
podras realizar la accion que deseas realizar.

1. Entrar a la opcion de **Subir imágenes** desde el menu lateral izquierdo.
