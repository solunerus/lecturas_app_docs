# Introducción

**Arquos OPR** es una herramienta diseñada para facilitar la gestión del control, 
monitoreo, fallas e incidentes de los medidores de agua, todo desde la comodidad 
de un móvil o tableta android.

## ¿Cómo empezar?

Puedes instalar la aplicación **[Arquos OPR](https://play.google.com/store/apps/details?id=com.nerus.lecturas_app)** desde la play store, una vez instalada
