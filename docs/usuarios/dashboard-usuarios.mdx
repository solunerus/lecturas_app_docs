# Dashboard de usuarios

Despues de haber ingresado la **URL API** tendras
acceso a la vista del dashboard de los usuarios donde
existen 3 apartados, **Lecturas**, **Validación** y
**órdenes**.

## Lecturas

En esta seccion podras `bajar`, `capturar` y `enviar`
datos de lecturas de los medidores, facilitando el tiempo y
trabajo.

### Bajar rutas

El usuario puede bajar las rutas que estan registradas para la
toma de lectura, estas estan ordenadas de tal manera que puedan
facilitar encontrar una ruta en especifica, la aplicacion te
pedira **Eligir un Subsistema** especifico, luego un **Sector** de ese
subsistema y por ultimo la **Ruta** de ese sector los cuales deberas
descargar.

### Capturar lecturas

Para poder capturar es necesario
[Iniciar sesión como empleado](/docs/introduccion/Iniciar_sesion#Empleado),
al seleccionar esta opción abrira una pestaña donde nos pedira **Seleccionar una ruta** estas se descargan en la opcion de
[Bajar ruta](/docs/usuarios/dashboard-usuarios#bajar-rutas), tendremos la opcion de
<span className="underline-custom">capturar todas</span> o ir
<span className="underline-custom">una por una</span>.


<center>
  <img
    src="/img/arquos_opr/usuarios/dashboard-usuario/capturar_1.jpg"
    alt="Configurar conexion validada"
    width="220"
  />
</center>

Si tu desicion fue <span className="underline-custom"> capturar una por una</span> y haber seleccionado la ruta que deseas 
capturar se abrira una nueva ventana, donde te mostrara todos lo medidores que se encuentrar
ubicados en la ruta seleccionada, podras ver la direccion, cuenta, medidor, 
localización y nombre, **Seleccionaras el medidor** al que quieras capturar 
en el sistema. 

<center>
  <img
    src="/img/arquos_opr/usuarios/dashboard-usuario/capturar_2.jpg"
    alt="Configurar conexion validada"
    width="220"
  />
</center>

Para facilitar las cosas se implementaron botones de ayuda para el usuario para ubicar 
rapidamente lo que busca, tanto de **busqueda** para encontrar lo que 
busca con cualquier dato, tambien busqueda por algo mas especifico como el 
numero de localización, ademas de integrar un boton para regresar a la **busqueda mas reciente**.
