# Validación

Si identificas alguna discrepancia en las lecturas, puedes modificarlas o recapturarlas desde
**Validación**. Este apartado cuenta con las mismas opciones que Lecturas:
[bajar rutas](/docs/usuarios/validacion/bajar-rutas),
[capturar validación](/docs/usuarios/validacion/capturar-validacion)
y [enviar ruta de validación](/docs/usuarios/validacion/enviar-ruta),
lo que facilita hacer el cambio cuando sea necesario.
