# Subir imágenes

En el menu desplegable de la izquierda se encuentra la opcion de enviar las imagenes que han sido adjuntadas
en las capturas de los datos, dentro podremos ver los datos generales de las capturas que se han realizado,
ademas se podran ver las imagenes adjuntas y con ayuda de lo botones **Enviar imágenes** y **Eliminar imágenes**
se podran realizar acciones dependiendo de que que se requiera realizar con las imagenes que se adjuntaron en
las capturas.
