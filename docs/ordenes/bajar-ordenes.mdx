# Bajar órdenes de trabajo

Para descargar las órdenes de trabajo, primero deberás iniciar sesión como [empleado](/docs/iniciar-sesion/empleado)
y después elegir una **población**, ya sea una en específico o todas las disponibles. Al seleccionarla, aparecerán las
**colonias** que pertenecen a esa población, donde nuevamente podrás elegir descargar una colonia en particular o todas a la
vez.
