# Enviar órdenes capturadas

Por último, podrás enviar al servidor las órdenes que ya hayas capturado. Primero deberás
iniciar sesión como [Usuario Arquos](/docs/iniciar-sesion/usuario-arquos) y después
elegir una **población**; al hacerlo, se mostrará el listado correspondiente, donde podrás
elegir enviar todas las órdenes capturadas o solo una en específico. Al seleccionar una opción,
te preguntará si la información es correcta; si es así, envía los datos al servidor presionando
el botón **confirmar**. Sabrás que se completó con éxito cuando aparezca un mensaje en
**verde** confirmando el envío.

:::note[IMPORTANTE]

El envío de datos al servidor puede tardar algunos minutos, dependiendo de la velocidad de tu
conexión a internet.

:::

En caso de querer **eliminar** las órdenes capturadas, puedes hacerlo mediante el ícono rojo en forma
de papelera que aparece al lado de cada colonia, ya sea para eliminar todas o solo una en
específico. Antes de eliminar se te pedirá confirmar la acción.
